先看一眼，一项真实任务会怎样一路升级。我们不把每一关做成互不相干的课程，而是让同一项任务持续向前。

先完成快速上手，准备好 Work Buddy 和企业身份，认识核心功能，也找到记忆的开启和管理入口。到新手启航村，找到岗位灵感，用六格任务卡定义任务，并得到第一份基线结果。然后进入装备工坊，为这项任务补上连接器、Skill、知识和自动化，并认识 Memory 与它们的分工。

接着，把这些能力装入个人专家，测试它在已知、未知、冲突和越权情况下是否可靠。再到业务任务训练场，用前面准备的能力完成真实业务产物，再参考六大工作场景的方法提示，把练习迁移到自己的岗位。到品质安全守护堡，核对事实、来源、权限和外部动作，产出修正版结果与通关证据。

最后，换一项新任务，独立复跑整套方法。你可以按顺序学习，也可以点击模块直接进入，或打开章节目录，按页码和关键词找到需要的内容。搜索 Memory 或记忆，可以进入快速上手中的“开启与管理 Memory”独立页，也能找到装备工坊里的说明。五个学习区域都可以通过目录进入。
