# 51Talk WorkBuddy 通关手册

51Talk AI Driver 互动学习手册的本地网页项目。当前版本包含 68 页，覆盖入场装备、新手启航村、装备工坊、AI 专家召唤工坊、业务任务训练场和品质安全守护堡。第五关现为 P59–68；全书已配置 67 页旁白与 1 页视频自带配音。

## 本地预览

在仓库目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:8765/>。无需安装前端依赖或执行构建。若浏览器阻止自动播放，点击“开启配音”。

任务卡和测验可自由打开；完成自检与测验成绩保存在当前浏览器的 localStorage 中，不会随 Git 同步。`workbuddy://` 链接需要本机已安装 WorkBuddy。

## 章节展开目录

点击任意页右下角的 **B 目录**，可打开章节展开目录；P3 模块路线页也有入口。第一层为 00 快速上手、01 新手启航村、02 装备工坊、03 AI 专家召唤工坊、04 业务任务训练场、05 品质安全守护堡。默认折叠，点击章节展开该章全部页面，显示实际页码与标题并可直接跳转，不再按每 10 页分页。搜索会自动展开匹配章节，仍支持输入页码直达。列表区域可滚动，当前所在章节及页面会标记；2026-09-10 新增企业 Skill 两页后，P1–25 不变，原 P26 起整体顺延 2 页；页面锚点保持不变。

目录由 `assets/page-directory.js` 根据主控制器的 `routes` 和页面标题生成，样式在 `assets/page-directory.css`；新增章节时同步更新章节起始路由即可。打开目录会暂停配音和视频，关闭不会自动续播；跳转仍复用原有页面播放逻辑。

## 文件说明

- `index.html`：当前手册的页面、交互、样式和音频路由。
- `assets/business-chapter.js` / `.css`：第四章的 12 页内容、三张任务卡、四道选择题和局部样式，复用主手册的导航与任务卡弹窗。
- `assets/safety-chapter.js` / `.css`：第五章的 10 页内容、终检任务卡、六题知识验收与学习记录收尾页。至少 5/6 分且三道安全关键题正确才通过知识验收；不代表真实业务验收。
- `assets/practice/safety-review.md`：终检练习单，复用第四关虚构材料和规则；不要求真实发送。
- `第五章-内容与口播稿.md`：P59–68 页面索引与逐页口播稿，配音已接入。
- `assets/practice/business-report/`：主线练习的虚构 CSV 与规则；同级 ZIP 为可下载练习包。修改源材料后需重新打包。
- `assets/videos/workbuddy-full-demo-20260909.mp4`：已确认收尾页的完整实操视频，本地副本约 30 MB、6 分 13 秒；嵌入 P47（`#business-demo`），支持播放、全屏与下载。同目录 JPG 为视频封面，原始导出仍保留在上级视频工程。
- `第四章-内容与录制说明.md`：P45–56 页面索引、视频占位与录制检查点。
- `assets/`：配音、截图、字体、品牌图片及已有内容数据。
- `voice/`：配音生成用文本。文件名前的数字属于生成时编号，当前页码以页面路由为准。
- `配音脚本-V1.md`：口播稿与配音说明。
- `scripts/generate-handbook-voice.py`：MiniMax 配音生成脚本，需要 Python、`certifi` 以及用户自行配置的 `MINIMAX_API_KEY`；未设置时尝试读取本机钥匙串。凭据不随仓库上传。
- `scripts/build-handbook-content.mjs`：历史内容整理脚本，依赖本仓库以外的课程底稿；不是当前手册的构建入口，预览无需运行。
