## 开始方式

把本目录作为指定输入，另选一个输出目录。不要修改原始文件。
看过主线示范后，在手册的同材料练习页按“检查输入 → 两个样例 → 确认后批量 → 生成文件 → 确认交付”的顺序练习。
先让 Agent 列出实际读取结果，而不是一口气做完。
